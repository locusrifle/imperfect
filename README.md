# imperfect

An operating system you build yourself, just by asking.

imperfect is one intelligence that is yours, on every screen you use. Its
interface is a web page, so it fits any screen and travels anywhere. Pick your
harness (Claude Code, Codex or Pi), then your model, and ask: what it makes
opens right beside the conversation and lives in your Workbench, with your
files and projects. It runs on Linux, with a desktop app and an Android app
that reach the same computer.

Film and website: [imperfect.computer](https://imperfect.computer)

## Get it

It is free and open source. Clone it, then ask your agent to read
`AGENTS.md`: it installs, updates (only the changes you pick), and undoes
everything from there.

    git clone https://github.com/locusrifle/imperfect ~/imperfect
    cd ~/imperfect
    ./install.sh          install, or bring the install up to this checkout
    ./install.sh update   see what is new
    ./install.sh phone    put the Android app on a phone
    ./install.sh undo     put the computer back the way it was

Bring your own Claude or ChatGPT subscription and sign in inside imperfect.

Rather not run it yourself? Rent your own imperfect computer in the cloud,
always on, for US$40 a month: [imperfect.computer/buy](https://imperfect.computer/buy).
